# infra-pi-home

This repo contains the things I run on a Raspberry Pi to power my smart home:

- Frigate
- Home Assistant
- Pi-hole
- Samba
- Teslamate
- Zigbee2mqtt

## Network

[UniFi UCG Ultra setup](docs/unifi-ucg-ultra.md) documents the gateway configuration,
VLANs, firewall policies and device connections. Keep it updated when changing the network.
